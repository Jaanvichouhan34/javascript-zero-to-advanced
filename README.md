# JavaScript Zero to Advanced 🚀

A **day-by-day, beginner-to-advanced JavaScript learning repository** designed to build **strong fundamentals** for **Web Development, MERN Stack, and Interviews**.

This repository focuses purely on the **JavaScript language**, without frameworks initially, so that the core concepts are crystal clear.

---

## 🎯 Goals of This Repository

- Learn JavaScript from **Zero → Advanced**
- Build a **strong foundation** for React, Node.js & MERN Stack
- Understand **how JavaScript works internally**
- Prepare **interview-relevant concepts**
- Maintain **clean, readable, and well-commented code**
- Follow a **day-by-day learning structure**

---

## 🧠 Who Is This For?

- Beginners starting JavaScript
- Web development learners
- MERN stack aspirants
- Students preparing for placements
- Anyone who wants **solid JavaScript fundamentals**

---

## 📅 Day-Wise Learning Breakdown

### 🟢 Beginner Level
- Variables (`var`, `let`, `const`)
- Data Types
- Operators & Conditions
- Loops (`for`, `while`, `for...of`, `for...in`)
- Functions & Arrow Functions
- Arrays & Array Methods
- Objects

### 🟡 Intermediate Level
- Scope & Hoisting
- Closures
- Higher Order Functions
- Callbacks
- Promises
- async / await

### 🔵 Advanced Level
- Error Handling
- Prototypes & Classes
- ES6+ Features
- Interview-focused concepts
- Logic-based mini projects
